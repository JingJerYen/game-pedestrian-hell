# 街屋貼圖槽（PNG）

街屋是程式用方塊蓋的（src/buildingkit.ts），這裡放要貼上去的 PNG（透明背景），
放好後到 buildingkit.ts 的 `DECAL_FILES` 對應的槽登記檔名，蓋房子時每個槽隨機抽一張。
PNG 還沒到的槽會顯示畫著槽名的佔位圖。

| 槽 | 貼在哪 | 建議比例 | 內容 |
|---|---|---|---|
| storefront | 一樓騎樓內牆 | 約 4:1（寬扁） | 玻璃門、貨架、燈光；整個店面正面 |
| banner | 騎樓上緣的橫幅招牌板 | 約 5:1 | 店名＋logo（例如 7-ELEVEN 條紋） |
| cube | 正面一角的方塊招牌，三個面 | 1:1 | 例如綠底「7」 |
| vsign | 直立長條招牌，兩個側面 | 約 1:4（瘦長） | 直排店名或廣告 |
| window | 鐵窗方塊正面（正面與側面都有） | 約 1:1 | 鐵窗格＋窗簾或冷氣 |

尺寸不用精準，程式會縮放到槽的大小；比例差太多會被拉變形。
建議每個槽準備 3 張以上，街景才不重複。
