# 車輛貼皮素材放這裡

把 PNG 圖檔直接丟進這個資料夾，檔名照下表，重新整理遊戲就會自動換皮。
三張圖（front/back/side）都到齊的車種才會換；缺圖的車種維持色塊，不會壞。

## 檔名與比例

| 檔案 | 內容 | 寬:高 比例 | 建議像素（可自訂，比例對就好） |
|---|---|---|---|

| `car_back.png` | 汽車車尾 | 1.9 : 1.4 | 96 × 71 |
| `car_side.png` | 汽車側面，**車頭朝右** | 4.2 : 1.4 | 288 × 96 |
| `truck_front.png` | 卡車車頭 | 2.3 : 2.6 | 92 × 104 |
| `truck_back.png` | 卡車車尾 | 2.3 : 2.6 | 92 × 104 |
| `truck_side.png` | 卡車側面，車頭朝右 | 7.6 : 2.6 | 304 × 104 |
| `scooter_front.png` | 機車正面（含騎士） | 0.9 : 1.3 | 45 × 65 |
| `scooter_back.png` | 機車背面 | 0.9 : 1.3 | 45 × 65 |

## 畫圖規則

- **車身畫白色或淡灰**，車窗、輪胎、保險桿畫深色——程式會把車色乘上去，
  一套圖自動變出調色盤裡的所有車色（深色部分不受影響）。
  想要固定顏色的部位（黃色計程車燈、紅色尾燈）畫成該顏色即可，但會被車色微調。
- 背景畫透明或直接塗滿都可以（貼在箱子上，透明處會看到車色底）。
- 像素風建議整套用同一種解析度密度（例如每公尺 24px），風格才一致。
- 頂面不用畫，程式用純車色補。
