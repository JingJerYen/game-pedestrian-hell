# 路旁建築模型

把街屋的 GLB 放這裡，然後到 `src/skins.ts` 的 `BUILDING_MODELS` 加上檔名（不含 .glb）。
遊戲會每棟隨機抽一款、用模型的實際面寬一棟接一棟排成連棟街景。

規格：
- 格式 GLB（glTF Binary，貼圖內嵌）。Blender：File → Export → glTF 2.0，Format 選 glTF Binary。
- 單位公尺。台灣街屋面寬約 4～6 m、一層樓約 3.2 m，三到五層。
- 正面朝 +Z（跟 Kenney 車輛、行人一樣）。
- 原點位置不拘：程式會自動把底部貼地、正面貼齊人行道外緣、面寬置中。
- 手機也要跑：單棟建議 5k 三角面以內、貼圖 1024 以內。
- 幾款都可以，越多款街景越不重複；沒放模型時用素色方塊撐著。
