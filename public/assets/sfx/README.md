# 音效

**預設不需要任何檔案。** 所有聲音都是 `src/sfx.ts` 用程式即時合成的（零下載、零解碼），
這個資料夾空的也完全正常。

## 想換成真的錄音

1. 把音檔（`.mp3` / `.ogg` / `.wav` 都可以）放進這個資料夾
2. 到 `src/tuning.ts` 的 `audio.sfx`，在那個音效那一行的 `file` 填檔名，例如：

   ```ts
   horn: { on: true, volume: 0.55, minGap: 3, jitter: 0.04, file: "horn.mp3" },
   ```

沒填 `file` 就用合成音，而且**不會**去發沒必要的網路請求；填了但檔案不在（或壞掉），
會自動退回合成音，遊戲照跑不會壞。

## 可以換的音效

| 名字 | 什麼時候響 |
|---|---|
| `horn` | 汽車/機車快撞到你：後方來車（同時亮「!」）或迎面來車靠近，各自在「剛出現」那一刻響（最短間隔 `minGap` 秒） |
| `bell` | 同上，但對方是腳踏車 |
| `hit` | 被車撞死 |
| `timeout` | 時間到失敗 |
| `clear` | 抵達目的地過關 |
| `start` | 標題畫面按下開始 |
| `tick` | 倒數剩 `audio.tickBelow` 秒起，每秒一聲 |
| `footstep` | 每走 `audio.stepDistance` 公尺一步 |
| `bump` | 撞到路障（不致死） |
| `stage` | 無盡模式升階 |
| `ambient` | 街道環境底噪（**循環播放**，換檔案時要找頭尾接得起來的 loop 素材） |

短一點比較不吵：一次性的音效 1 秒內，`footstep` / `tick` 0.1 秒左右就夠。

## 開關

- 整套關掉：`tuning.ts` 的 `audio.enabled = false`
- 單獨關掉某一個（調手感時很方便）：那一行的 `on: false`
- 玩家自己開關：遊戲中按 **M**（會記在瀏覽器，下次開還記得）
